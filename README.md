Para que funcionen los videos embed de la página, se deberá hacer lo siguiente en Visual Studio code:

1. Instalar la extensión "Live Server", del autor "Ritwick Dey"
2. En la barra de herramientas inferior, figurará la opción "Go Live", que comenzará a hostear el "index.html" actual en el puerto 5500 de la computadora, y se abrirá la página automáticamente.
3. Los videos podrán verse e incluso seleccionar la opción de pantalla completa.
4. Listo!
